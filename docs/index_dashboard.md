# The Index Dashboard.

This is the first page user looks at when they have signed up.

- If they haven't filled their Details tell them to fill their details.
- These are the models in which the SamaajMember should have their details saved in.
  - SamajMember
  - SamajMemberMobileNumber
  - SamajMemberEmail
  - SamajMemberAddress
  - SamajMemberEducationalQualification
  - SamajMemberOccupation
  - SamajMemberIncome

- Show Progress as Pie Chart.
- Also Show buttons for `Add new samaaj member`, `View samaaj members`.
- Show Metrics of Members Added By you (logged in user).

---

The UI should be mobile first responsive. As mostly the users will be accessing through mobile phones.

- We are using Tailwindcss, flowbite.
- Minimal, easy to read and access.
- Mobile Phone interactions and quirks should be kept in mind, and make the app more accessible.
