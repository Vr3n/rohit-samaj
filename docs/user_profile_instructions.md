# User Profile Page.

Implement a User Profile Page (@templates/users/profile.html) where.

1. User can see their Profile Picture.
2. Edit their Mobile Number.
3. Add Email Id and Mobile Numbers.
4. Link Other Social Media Accounts like LinkedIn, X, Facebook, whatsapp.

---

The UI should be mobile first responsive. As mostly the users will be accessing through mobile phones.

- We are using Tailwindcss, flowbite.
- Minimal, easy to read and access.
- Mobile Phone interactions and quirks should be kept in mind, and make the app more accessible.
